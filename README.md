# Juego Unity

Proyecto desarrollado en Unity como parte del desarrollo de un videojuego RPG de fantasía.

## Descripción

En esta versión se ha creado una escena jugable con un terreno personalizado, caminos, montañas, rocas, 
árboles, vegetación, construcciones y otros elementos del entorno.

También se incluye un personaje controlable con animaciones y un enemigo de prueba.

## Características actuales

- Terreno personalizado
- Texturas de césped, camino, roca y tierra
- Montañas y desniveles
- Árboles, rocas y vegetación
- Construcciones decorativas
- Personaje jugable
- Animaciones de movimiento
- Sistema básico de combate
- Enemigo de prueba

## Cómo ejecutar el proyecto

1. Abrir el proyecto desde Unity Hub.
2. Utilizar Unity 6.
3. Abrir la escena principal del proyecto.
4. Presionar Play para ejecutar la escena.

## Controles

- Movimiento: WASD
- Cámara: Mouse
- Salto: Space

## Estado del proyecto

Este proyecto se encuentra actualmente en desarrollo y corresponde a una primera versión funcional del entorno 
y las mecánicas principales.
